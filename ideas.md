# HydroNex design brief

## Theme Name
**Tidal Observatory**

## Intro
A dark Earth-observation command center that treats water as a living signal: calm enough for analysis, alive enough to feel like the system is continuously reading the planet.

## Design movement
Editorial geospatial intelligence with a tactile oceanographic layer: crisp data surfaces over an atmospheric, softly animated field.

## Core principles
1. Evidence before decoration.
2. Motion explains change and attention, never spectacle.
3. The map is a data canvas, not a generic basemap.
4. Every risk state is named as well as colored.

## Color philosophy
Near-black navy canvas; cobalt and cyan for water and active states; mint for healthy signals; amber and coral for attention and criticality. Gradients are used only as atmospheric highlights.

## Layout paradigm
Persistent left rail, compact top command bar, layered panel canvas, and a hero visualization that can hand off to a selected-waterbody analysis rail.

## Signature elements
Animated latitude grid, radial water rings, micro-sparkline strips, translucent metric chips, and a “DETECT / ANALYZE / EXPLAIN / PRIORITIZE” micro-label system.

## Interaction philosophy
The interface should react immediately to hover, selection, and filter changes. Selected waterbodies should echo across map, charts, and detail rail.

## Animation
Short 180–500ms transitions, staggered entrance, slow pulse only for map markers, and reduced-motion support.

## Typography system
Inter/system sans for primary UI; IBM Plex Mono / ui-monospace for coordinates, timestamps, API states, and numeric readouts.

## Brand essence
HydroNex turns satellite and rainfall signals into confident, traceable water resilience decisions.

## Brand voice
Calm, precise, analytical, human. Prefer “observed association” to “cause”; prefer “analytical recommendation” to “instruction”.

## Wordmark / logo
A cyan waterbody silhouette intersected by a mint orbit line, built from two bold filled shapes and negative space. The mark is recognizable at 24px and extends naturally into a wordmark.

## Signature brand color
**Hydro cyan** `#5CE1E6`.
